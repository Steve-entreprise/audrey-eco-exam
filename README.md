# 🌿 Audrey Eco Exam

**Des examens sans papier.** Démonstration interactive pour créer, passer et corriger un examen sur téléphone ou ordinateur, sans une seule feuille.

## Fonctionnalités

- **Espace professeur** : création d’examens (QCM de 2 à 6 choix, réponse courte avec plusieurs variantes acceptées, rédaction avec feuille de dessin), code d’examen généré à la publication, brouillon sauvegardé automatiquement.
- **Espace élève** : règles avant de commencer, chronomètre, navigation entre les questions, réponses conservées si la page se recharge, plein écran au choix.
- **Feuille de dessin** : crayon, ligne, rectangle, cercle, gomme, couleurs, épaisseurs, retour en arrière.
- **Surveillance honnête** : les sorties d’onglet, de fenêtre ou du plein écran sont signalées au professeur — un indice, jamais une preuve de triche.
- **Résultats** : correction automatique des QCM et réponses courtes, notes des rédactions, commentaires, export CSV, compteur de feuilles non imprimées.

Examen de démonstration : code **AUDREY**.

## Utilisation

Tout le site tient dans un seul fichier, `index.html`. Il suffit de l’ouvrir dans un navigateur ou de l’héberger (GitHub Pages, Netlify…).

> Démo pour exposition : les données restent dans le navigateur (localStorage). Les alertes ne sont pas transmises entre appareils. Pour une utilisation scolaire réelle, une version avec serveur et authentification sera nécessaire.
